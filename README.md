ACM Membership System

A web-based membership management portal developed as part of an ACM project to add, delete, edit and archive club members, organize teams, and maintain membership records.

Features

Member management: Add, view, update, archive, restore, and permanently delete members.

Authentication: User registration and login.

Role-based access: Separate permissions for administrators and regular users.

Team management: Organize members into teams.

Dashboard: View membership statistics.

Persistent storage: Store member and account information using SQLite.

Technologies Used

Frontend: React, Vite

Backend: Node.js, Express.js

Database: SQLite

Authentication: JSON Web Tokens (JWT), bcrypt

Version control: Git and GitHub

Open the local URL displayed by Vite in your browser.

Prerequisites: Install node.js and npm.
    Run the backend using node server.js and the frontend with npm run dev.
